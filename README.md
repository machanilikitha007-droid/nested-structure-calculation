# Nested Structure with Calculation

## Author
M.Likitha

## Description
This program demonstrates performing a calculation using
members of a nested structure.

The Rectangle structure contains a Dimensions structure.
The length and width stored inside the nested structure
are used to calculate the area.

## Concepts Used
- Nested structure
- Structure member access
- Floating-point calculation
- Structure initialization
- Arithmetic operators

## How to Run

gcc nested_structure_calculation.c -o nested_structure_calculation

./nested_structure_calculation
